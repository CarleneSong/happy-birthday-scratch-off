# 🎂 生日幸运刮刮乐（Birthday Scratch）

> 一个可以用「配置文件」定制的解谜刮刮乐网页。
> 贺卡封面 → 刮开幸运格 → 破解故事化密码题 → 输入兑换码领取礼物 → 通关终幕。

把你想送出的礼物写成N个故事谜题，让对方用智慧一件件「挣」到手。

## ✨ 特性

- 🎴 **贺卡封面**：3D 翻页开场，文案全自定义
- 🖌️ **真·刮刮乐**：Canvas 涂层，手指/鼠标刮开（刮开 40% 自动揭晓）
- 🧩 **故事化谜题**：谜面以故事呈现（深夜字条、老手机、旧金库……），不是干巴巴的题目
- 🗝️ **分阶段解锁**：第 1 格默认可玩，其余格子需输入密钥解锁——密钥由你当面告诉对方，把线上解谜变成线下见面
- 🏆 **兑换码机制**：谜底不必是礼物名，破译出密码即解锁，防剧透
- 📊 **进度总览**：主界面实时显示 8 格状态（🔒 未解锁 / ⏳ 待破解 / ✅ 已破解 + 奖品名），方便你按进度发礼物
- 💾 **进度本地保存**：localStorage 按设备独立存储，刷新不丢进度，互不干扰
- 🎉 **通关撒花**：答对撒花 + 全通关大撒花终幕
- 📱 **移动端适配**：微信内置浏览器可正常打开

## 🚀 快速开始

### 方式一：本地试玩（30 秒）

1. 下载本仓库（Code → Download ZIP）并解压
2. 用任意文本编辑器打开 `config.js`，照注释改成你的内容
3. 双击 `index.html`，浏览器里直接试玩

### 方式二：部署到线上发给对方（推荐）

静态托管任选其一，都免费：

**GitHub Pages**
1. Fork 本仓库（或新建 Public 仓库，上传 `index.html` + `config.js` + `docs/`）
2. 仓库 Settings → Pages → Branch 选 `main` / `/ (root)` → Save
3. 1~2 分钟后访问 `https://<你的用户名>.github.io/<仓库名>/`

**Vercel / Netlify**
1. 注册后导入仓库，一路默认设置部署即可
2. 或直接把项目文件夹拖进 [Netlify Drop](https://app.netlify.com/drop)

> 部署后把链接发给对方即可，微信里可以直接打开。

## 📖 如何写自己的谜题

**你唯一要改的文件是 `config.js`**，全部字段都有注释说明：

| 字段 | 说明 |
|------|------|
| `card` | 贺卡封面：称呼、祝福语、标题 |
| `unlockKey` | 解锁密钥（字符串）；`null` = 所有格子直接可玩 |
| `finalMessage` | 全部通关后的终幕文案 |
| `puzzles[].icon` | 格子图标（emoji） |
| `puzzles[].label` | 格子名称 |
| `puzzles[].prize` | 奖品短名（仅破解后在进度总览显示，防剧透） |
| `puzzles[].reward` | 破解后的奖励弹窗文案 |
| `puzzles[].answers` | 可接受的兑换码数组（不区分大小写/空格） |
| `puzzles[].body` | 谜面正文，支持 HTML（`<br>` 换行、`.code` 代码块、`.hl` 高亮） |
| `puzzles[].pigpenWord` | （可选）猪圈密码：填英文单词，自动渲染图纸 + 密文 |

### 谜题灵感

内置 5 种示例谜题类型（藏头诗 / 凯撒密码 / 九宫格连按 / 猪圈密码 / 二进制格栅）。
更多可直接套用的谜题模板见 **[docs/谜题模板库.md](docs/谜题模板库.md)**（14 个模板，含谜面故事、解法、难度分级）。

## 🎮 玩法设计建议（血泪经验）

1. **答案格式提示要给，解法提示不要给** —— 谜面只说"答案格式：一个英文单词"，解法让他自己顿悟
2. **线上线下可分步进行**：第 1 题线上破解见面地点，其余 N 题可以等见面后口头给密钥再解，线下体检对方抓耳挠腮破解谜题的乐趣
3. **设计者可看进度**：随时打开链接就能看到对方破解到第几格，方便安排发礼物节奏

## 🧪 测试技巧

- **连点主标题 5 次** → 重置全部进度
- 进度按设备独立存储，你自己测试不会污染对方的进度
- 换一套配置时记得改 `storageKey`，避免旧进度残留

## ⚠️ 已知限制

- 答案写在前端代码里，懂技术的人按 F12 能看到源码（对绝大多数场景够用；真碰上扒源码的对象，那也算他赢了 😄）
- 需要联网加载的静态托管；纯本地双击打开也完全可用
